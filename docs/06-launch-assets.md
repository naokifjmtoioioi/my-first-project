## 1週目の投稿ドラフト（6本）

倫理ガードレール（断定的効果保証をしない・恐怖訴求をしない・医療の代替を謳わない）を反映済み。投稿前に最終チェックすること。

### ① 気づき・学び系（2本）

**投稿1**
```
「子どもを変えよう」とするほど、うまくいかないことがあります。
子どもは、親の緊張や不安を敏感に感じ取っているから。
まず変えられるのは、自分の内側だけ。
```

**投稿2**
```
潜在意識は「〜しなければ」より「〜だったらいいな」を素直に受け取ると言われます。
「学校に行かせなきゃ」より先に、
「今日一日、穏やかに過ごせたらいいな」と自分に言ってみる。
それだけで空気が変わることがあります。
```

### ② 共感・あるある系（2本）

**投稿3**
```
「今日は学校行けそう?」と聞いてしまってから後悔する夜。
わかります、その気持ち。
聞いてしまう自分を責めなくていい。
それだけあなたが子どものことを想っているということだから。
```

**投稿4**
```
不登校の子を持つと、ママ友との会話にふと入れなくなる瞬間がある。
子どもの話題が出るたびに、心のどこかがザワつく。
そのザワつき、一人で抱えなくていい。
```

### ③ 体験・エピソード系（1本、誇張なし）

**投稿5**
```
[実体験に置き換え: 例]コーチングを学ぶ中で気づいたのは
「相手を変えようとする力は、実は自分に返ってくる」ということでした。
子育てでも同じかもしれない、と思っています。
```
