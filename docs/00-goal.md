# 目標設定

## 最上位目標

- **年間収益目標: ¥50,000,000（税抜想定）**
- 期間: `data/config.json` の `start_date` 〜 `end_date`（デフォルトは 2026-08-01 〜 2027-07-31 の12ヶ月）
- 「収益」は売上ベースとし、原価・経費を差し引いた利益ベースにするかは事業ドメイン確定後に再定義する

## 事業ドメイン: 確定済み

**潜在意識×コーチング（不登校の子を持つ保護者向け）**。詳細な商品設計・フェーズ計画は `docs/04-business-model.md`、選定理由は `docs/02-domain-selection.md` を参照。

## ブレークダウン（2本立て）

週7時間・初期資金¥500,000のソロスタートという制約上、¥50,000,000を単純な均等割りで追うのは非現実的（`docs/04-business-model.md` の現実性チェック参照）。そのため「現実ライン」と「ストレッチライン（北極星）」の2本を併記し、`scripts/progress.py` では北極星（¥50,000,000）に対する達成率を、判断の目安には現実ラインを使う。

| 期間 | 現実ライン（累計） | ストレッチライン=北極星（累計） |
|---|---|---|
| 2ヶ月目末（検証期終了） | ¥300,000 | ¥8,333,333 |
| 6ヶ月目末（個別コーチング立ち上げ後） | ¥3,500,000 | ¥25,000,000 |
| 12ヶ月目末 | ¥10,000,000〜¥15,000,000 | ¥50,000,000 |

実際には立ち上げ初期は収益が小さく、後半に伸びる「Jカーブ」になる想定。この基準線は事業モデルの実績が出次第、四半期ごとに見直す。

## 「自動的に仕組みを構築する」の定義

このプロジェクトでの「自動化」とは、以下を満たす状態を指す:

1. 収益を生む一連のプロセス（リサーチ→企画→制作/開発→集客→販売→計測）の大部分を、人間の常時稼働ではなくAIエージェント（Claude Codeのサブエージェント／スクリプト／定期実行トリガー）が担う
2. 人間（あなた）の役割は、方針決定・最終承認・資金や外部アカウントに関わる意思決定に限定される
3. 進捗・収益は `data/revenue.csv` に記録され、いつでも `scripts/progress.py` で可視化できる

## 重要な前提（正直な期待値設定）

- AIエージェントは調査・企画・コンテンツ制作・自動化スクリプトの実行を代行できるが、実際の入金・契約・広告出稿・支払いなど「外部への影響を伴う行為」は人間の承認が必須
- 「自動で儲かる」ことを保証する仕組みではなく、**意思決定と実行速度を最大化するための体制**である
- 年間5000万円という目標は事業ドメインによって難易度が大きく異なるため、`docs/02-domain-selection.md` でドメインを確定させることが最初のマイルストーン
