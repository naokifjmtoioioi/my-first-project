# フェーズ1: X（旧Twitter）発信戦略

`docs/04-business-model.md` フェーズ1（検証期）の実行計画。主軸チャネルを **X** に決定。

## ペルソナ（想定読者）

具体名を1人置いて発信のブレをなくす。

> **Aさん（40代・母親）**
> 中学生の子どもが半年前から不登校。仕事と家庭を両立しながら、学校・スクールカウンセラーには相談したが「様子を見ましょう」で終わり、手応えがない。育児本やSNSで情報収集する中で「子どもではなく自分の在り方を変える」という考え方に触れ、気になっている。スピリチュアル/潜在意識系の言葉にも抵抗はないが、怪しい高額商材には警戒心がある。

投稿を書く際は「Aさんに向けた1通の手紙」のつもりで書く。

## アカウント設計

- **プロフィール文言の要素**: 誰の（不登校の子を持つ保護者）／何を（潜在意識×コーチングで）／どうする発信か（親の在り方から家庭の空気を変えるヒント）、実績・資格があれば明記、断定的な効果保証はしない
- **プロフィールリンク**: 無料相談 or 診断コンテンツへの導線（LINE公式アカウント推奨。個別DMより取りこぼしが少ない）
- **固定ポスト**: 自己紹介 + 提供価値 + 無料相談への導線

## コンテンツピラー（4本）

| ピラー | 目的 | 投稿頻度目安 |
|---|---|---|
| ① 気づき・学び系（潜在意識×親の在り方） | 専門性の提示、保存・引用されやすい | 週2〜3 |
| ② 共感・あるある系（不登校家庭のリアル） | エンゲージメント獲得、「わかってくれる人」認知 | 週2 |
| ③ 体験・エピソード系（誇張なしの気づき・変化） | 信頼構築 | 週1 |
| ④ 緩やかな告知（無料相談・プログラム案内） | 導線への送客 | 週1 |

**倫理ガードレール（`docs/04-business-model.md` 準拠、再掲）**: 「これで学校に戻れる」等の断定表現、恐怖訴求・煽り、医療/心理療法の代替を謳う表現はピラー①〜④すべてで禁止。エピソード投稿は本人の許可なく実話を誇張しない。

## 週7時間の配分（フェーズ1目安）

| 作業 | 時間 | 備考 |
|---|---|---|
| コンテンツ下書きの確認・仕上げ | 2h | 集客AIが下書き作成→人間が倫理ガードレール込みで確認・仕上げ |
| 投稿・エンゲージメント（リプライ・引用） | 2h | 特にピラー②への反応を大切にする |
| DM対応・無料相談の実施 | 2h | 申込があった分のみ |
| 振り返り・翌週の投稿ネタ整理 | 1h | 反応の良かった投稿を分析 |

投稿頻度は無理のない**週5投稿**を目安に開始し、時間が確保できる場合のみ増やす。

## 導線（ファネル）

```
X投稿 → プロフィール → 無料相談 or 診断コンテンツ（LINE公式）
      → 個別相談（30分・オンライン） → 個別コーチングプログラム提案
```

- 無料相談への導線は毎回同じにする（覚えてもらいやすくする）
- 診断コンテンツ（例:「あなたの『親としての在り方』タイプ診断」）はリード獲得の入口として企画AIに設計を依頼

## 初期KPI（8週間の目安・控えめな仮説）

| 指標 | 8週間後の目安 |
|---|---|
| フォロワー数 | 300〜500 |
| プロフィールクリック率 | 継続計測（ベンチマークがないため初期は絶対数より推移を見る） |
| 無料相談申込 | 3〜8件 |
| 個別コーチング成約 | 0〜2件（フェーズ1はモニター価格での実施でも可） |

**注意**: これは仮説であり保証ではない。4週間ごとに振り返り、反応が悪いピラーは差し替える。

## タスク分担

- **集客AI**: ピラーごとの投稿下書き作成（週5本 + 告知1本）、倫理ガードレール準拠チェックの一次スクリーニング
- **企画AI**: 診断コンテンツ・無料相談の設計
- **人間**: 最終投稿の確認・投稿実行、DM対応、個別相談の実施（Xアカウントへのログイン・投稿操作は人間が行う）

## 次のアクション

1. Xアカウントのプロフィール文言・固定ポストを人間が確定し設定
2. LINE公式アカウント（または代替の無料相談導線）を用意
3. 集客AIに1週目分（5投稿+告知1本）の下書き作成を依頼
4. 投稿開始後、`data/revenue.csv` とは別に週次でKPI（フォロワー数・相談申込数）を記録する運用を検討
