# 事業ドメイン選定フレームワーク

事業ドメインは未確定。年間¥50,000,000という目標に対して、AIエージェント体制で自動化しやすく、かつ現実的に到達可能なドメインを選ぶための評価軸と候補一覧。

## 評価軸（各5点満点）

| 軸 | 説明 |
|---|---|
| 自動化適性 | 調査・制作・運用のうちAIが代行できる作業の割合が高いか |
| 初期資金負担 | 立ち上げに必要な資金が小さいか（大きいほど低スコア） |
| 収益化までの期間 | 最初の売上が立つまでの期間が短いか |
| スケーラビリティ | 労働時間を増やさずに収益を伸ばせるか |
| 市場規模 | ¥50,000,000/年に届く市場規模・単価構造があるか |
| 参入障壁/競合 | 過当競争でなく、差別化の余地があるか |
| 保有スキル適合 | 現時点のスキル・アセットとの適合度 |

## 候補ドメイン（たたき台・スコアは仮）

| ドメイン | 自動化適性 | 初期資金負担 | 収益化速度 | スケーラビリティ | 市場規模 | 参入障壁 | スキル適合 | 合計/35 |

> 「スキル適合」列と最終スコアは、あなたの現状のスキル・資金・使える時間をヒアリングした上でリサーチAI/企画AIが埋める。ここはまだ仮の叩き台。

## 次のアクション

1. あなたの現状（使える初期資金、週あたりの稼働可能時間、既存のスキル・アセット・実績、興味関心）をヒアリング
2. 上記候補のうち上位2〜3ドメインについて、リサーチAIが詳細な市場調査を実施
3. 企画AIが各ドメインの収益シミュレーション（単価×販売数×期間で¥50,000,000到達の現実性）を作成
4. 人間が最終ドメインを確定し、`docs/00-goal.md` のブレークダウンを更新
